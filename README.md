# 香港職安登記冊

獨立編列的香港職業安全及健康官方紀錄靜態網站。供查閱 2025年11月19日至2026年11月20日已核對的官方紀錄，分三層閱讀：關注與跟進、形態歸類、完整登記冊。

此冊是資料匯編。**此冊不是政府刊物，亦不是法律意見。** 頁面不模仿政府網站，不設登入，亦不收集個人資料。

## 資料截止

**2026年11月20日 08:59（香港時間）。** 該次例行掃描未發現新的意外、檢控、職安警示、法例／規例、工作守則或指引。

本冊共 85 筆官方紀錄：意外 23、檢控 31、職安警示 25、指引 3、法例／規例 2、工作守則 1。日期以香港時間為準。只標明月份的職安警示歸入該月。

## 來源

紀錄正文來自本倉庫 `sources/`，建置時逐筆核對，不作改寫：

- [`sources/REGISTER.md`](sources/REGISTER.md)：英文登記冊原文，包括日期、類型、標題、英文摘要、英文法例編號、狀態、英文更新行與官方來源網址。
- [`sources/ZH_OFFICIAL_SUMMARIES.md`](sources/ZH_OFFICIAL_SUMMARIES.md)：85 筆官方中文摘要、中文法例編號、中文更新行，以及全部 39 則來源說明。網頁以官方中文摘要為主要閱讀摘要；若中英文官方文本有出入，頁面從已引用的中文來源。來源說明以「來源說明」照錄。
- [`sources/presentation.json`](sources/presentation.json)：紀錄識別碼、來源連結標題、形態歸類與跟進線索。它不改寫正文；建置時會核對標題、類型、法例編號與來源網址。

官方文本引自香港特別行政區政府新聞公報（勞工處）及勞工處職安警示、安全提示、工作守則與指引專頁。各筆頁面均列出來源網址。

職安警示與安全提示是兩種不同項目。東涌 2026年10月7日致命事故已有勞工處安全提示，頁面另以「已有安全提示（並非職安警示）」標示；該筆紀錄狀態仍是 official（官方），類型仍是意外，不是職安警示。沙田 2026年11月5日及東涌該筆，截至上述截止時間，官方職安警示索引仍未有對應的 10 月或 11 月職安警示。
